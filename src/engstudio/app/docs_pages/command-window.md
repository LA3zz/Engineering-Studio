# Command Window

Type a command and press Enter. Up/Down recall earlier commands; history is kept between
sessions. Errors are shown in red and also listed in [Diagnostics](diagnostics.md).

Supported now (stand-in kernel): `x = 5` assigns a number, `x` shows it, `clc` clears the
window, `demo_plot [N]` opens a demo figure (see [Figures](figures.md)).

Shortcuts: Ctrl+0 focus the Command Window, Ctrl+Shift+L clear it.
