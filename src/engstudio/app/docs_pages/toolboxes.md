# Toolbox browser

Lists every command, grouped into categories (Elementary math, Plotting, Control systems, ...)
and the engineering toolboxes (Mechanical Engineering, Thermodynamics, Fluid Mechanics, Heat
Transfer, Electrical and Electronics, Materials and Lab Data, Structures and FEA, Robotics,
Aerospace). All groups start collapsed: click the arrow to open one.

- **Search:** type part of a name or description in *Filter functions...*; matching groups
  open. Clear the box to collapse them again.
- **Details:** click a function to see, in the pane below the list, how to call it, what each
  input means (with units, allowed range and default), the outputs, the fields of a result
  struct, and an example you can copy.
- **Insert:** double-click a function to put its name in the Command Window.

The same help is printed by `help name` in the Command Window (for example `help sdof`), and
while you type a call such as `plot(x, ` a tip shows what the next input should be (see
[Script editor](script-editor.md)).
