Introduction

Engineering Studio is an offline, MATLAB-style desktop environment for engineering students. You write .m scripts in the same language you use in MATLAB, run them with F5, and get results, figures, block-diagram simulations and engineering toolboxes without a licence server or an internet connection.

This manual explains every part of the program: the desktop and its panels, the language, mathematics, plotting, control systems, the block-diagram simulator, lab data files, and the nine engineering toolboxes. The last chapters are complete references: every toolbox function with the meaning, unit and limits of each input, every simulation block with its parameters, and every built-in command with its calling forms.

Tip. Everything in the reference chapters is also available inside the program: click a function in the Toolboxes panel, type help name in the Command Window, or just start typing a call such as plot(x, and read the tip that appears.

Installing, updating and removing

  1. Download EngineeringStudio-Setup-<version>.exe from the project's GitHub Releases page (Windows 10 or 11, 64-bit).
  2. Run it. Windows may say "Windows protected your PC" because the installer is not code-signed; click More info and then Run anyway.
  3. No administrator rights are needed. The installer offers a desktop shortcut and an Open with → Engineering Studio entry for .m files (your default program for .m files does not change).

Updating: choose Help → Check for Updates. The program asks GitHub (only when you click) whether a newer release exists and offers to open the download page. Running a newer installer upgrades the program in place and keeps your settings, layout, themes and scripts.

Removing: use Settings → Apps → Installed apps → Engineering Studio → Uninstall. Your own scripts are never deleted.

Arranging panels and themes

  • Drag a panel's title bar to move it, drop it on another panel to make tabs, or drag it out to float it as its own window. The layout is saved when you exit.

Command Window

Type a command at the >> prompt and press Enter.

  • A result is shown unless the line ends with a semicolon: x = 5 shows x = 5, x = 5; shows nothing.
  • Up/Down recall earlier commands (kept between sessions); Esc clears the line.
  • Pasting several lines runs them together as one block.
  • Errors appear in red and are also listed in the Diagnostics panel.
  • help name prints how to call a function and what its inputs mean; clc clears the window; Ctrl+Shift+L does the same.
  • While you type a function call, a call tip above the input line shows how the function can be called, with the input you are typing in bold underline (see Call tips).

Script editor and running scripts

Scripts are plain text .m files. The editor has tabs, syntax highlighting (keywords, comments including %{ ... %} blocks, strings and numbers) and asks before closing a tab with unsaved changes. Scripts that are open when you exit reopen at the next start (untitled scripts are not kept).

ActionKeyWhat happens
Run ScriptF5Saves nothing automatically; runs the whole script in the current tab. File names in the script are also looked up in the script's own folder.
Run Selection or LineF9Runs the selected text, or the line with the cursor.
StopShift+F5Stops a running script, loop, simulation or long calculation.

Output goes to the Command Window, variables to the Workspace, errors (with their line number) to Diagnostics, and every figure opens in its own window. A script may end with local functions:

r = 0:0.5:2;
a = circle_area(r)

function A = circle_area(r)
    A = pi*r.^2;
end

Double-clicking a .m file in Windows Explorer (with Open with → Engineering Studio) opens it in the running program instead of starting a second copy.

Call tips

Call tips appear in both the editor and the Command Window as soon as the cursor is inside the parentheses of a known function. They show:

  • every way of calling the function, one per line; the input at the cursor is bold and underlined;
  • calling forms that cannot take that many inputs in grey;
  • for toolbox functions, what the current input means, its unit, allowed range or words, and its default value; for other functions, a one-line summary.

Commas inside [ ], { } and quoted text do not count as new inputs. The tip disappears when the closing parenthesis is typed, when the cursor leaves the call, or when you press Esc.

Workspace, Current Folder, Toolboxes, Diagnostics

Workspace lists every variable with its class, size and a short preview. Click a column header to sort, type in the filter box to narrow the list, and double-click a row to display the variable in the Command Window. Right-click for Clear Selected and Clear All. Save... writes the selected variables (or all) to a MATLAB .mat file and Load... reads one back; see Saving and loading variables.

Current Folder shows the working folder. Use Up, Browse, or type a path and press Enter. Double-click a folder to enter it, a .m file to open it in the editor, or a .esmodel file to open it in the model editor. The Current Folder is the working folder: relative file names such as readmatrix('data.csv') or saveas(gcf, 'plot.png') refer to it, and the commands cd and pwd change and show it (the panel follows).

Toolboxes lists all commands in groups (Elementary math, Plotting, Control systems, ...) and the nine engineering toolboxes. Groups start collapsed; click the arrow to open one. Type in Filter functions... to search names and descriptions. Click a function to see its complete help in the pane below the list (calling forms, inputs with units and limits, outputs, result fields and an example); double-click to insert its name into the Command Window.

Diagnostics collects errors, warnings and information from every run (the newest 500 are kept). Filter by severity with the buttons and press Clear to empty the list.

The language

Engineering Studio runs the MATLAB language. This chapter is a compact tour; everything shown works as in MATLAB.

Variables, numbers and display

a = 3            % shows a = 3
b = 2.5e-3;      % semicolon: no output
c = 3 + 4i       % complex number
d = abs(c)       % 5
7*6              % an unnamed result is stored in ans
x = pi; y = e;   % constants pi and e

Names are case sensitive, start with a letter and may contain letters, digits and underscores. Comments start with %; %{ and %} on their own lines enclose a block comment; ... continues a statement on the next line.

Matrices and indexing

A = [1 2 3; 4 5 6]      % 2-by-3: spaces or commas separate columns, ; separates rows
v = 0:0.25:1            % start:step:stop
z = zeros(2, 3); I = eye(3);
A(2, 3)                 % one element (row 2, column 3)
A(:, 2)                 % whole second column
A(end, :)               % last row
A(A > 2)                % logical indexing: elements greater than 2
A(1, :) = [7 8 9];      % assign a row
B = [A; 10 11 12]       % append a row
n = numel(A); [r, c] = size(A);

Text, cells and structures

name = 'beam';                       % char array (single quotes)
msg = sprintf('%s of %.2f m', name, 2.5)
parts = strsplit('a,b,c', ',');      % cell array of texts
c = {1, 'two', [3 4]};               % cell array: any values
second = c{2}                        % curly braces read the content
s.E = 200e9; s.name = 'steel';       % structure with fields
s.E / 1e9
f = fieldnames(s);

Control flow

total = 0;
for k = 1:5
    if mod(k, 2) == 0
        continue            % skip even numbers
    end
    total = total + k;
end
n = 0;
while n < 3
    n = n + 1;
end
mode = 'fast';
switch mode
    case 'fast'
        dt = 0.1;
    case {'slow', 'safe'}
        dt = 0.01;
    otherwise
        dt = 1;
end
try
    x = [1 2] * [3 4];      % size mismatch
catch err
    disp(err.message)
end

Also available: break, return, elseif, and error(...) / warning(...) to report problems.

Functions and function handles

f = @(x) x.^2 - 2;            % anonymous function
f(3)
root = fzero(f, [0 2])
g = @sin;                     % handle to a named function
integral(g, 0, pi)
[m, s] = stats([1 2 3 4])

function [m, s] = stats(x)    % local function with two outputs
    m = mean(x);
    s = std(x);
end

Command syntax works for common commands: hold on, grid on, axis equal, close all, clear all, colormap jet, cd .., help plot.

Differences from MATLAB

  • About 350 built-in commands plus 85 toolbox functions; commands from MATLAB toolboxes that are not listed in the command reference are not available.
  • No classes (classdef), global/persistent variables, struct arrays, tables, or N-dimensional arrays (matrices are 2-D). readtable returns a struct of columns.
  • format long is not available yet; unique has one output.
  • Symbolic systems of equations use cell arrays: solve({eq1, eq2}, {x, y}).
  • Plot windows are interactive (pan/zoom) but property editing is limited to the set/get properties used by the plotting commands.

Mathematics

Linear algebra

A = [4 -2 1; -2 4 -2; 1 -2 4];
b = [11; -16; 17];
x = A \ b                 % solve A x = b (preferred over inv(A)*b)
d = det(A), r = rank(A), c = cond(A)
[V, D] = eig(A);          % eigenvectors (columns of V) and eigenvalues (diagonal of D)
[L, U, P] = lu(A);  R = chol(A);  [U2, S, V2] = svd(A);

Calculus, roots and optimisation

f = @(x) exp(-x.^2);
I = integral(f, -Inf, Inf)            % numerical integral
x = 0:0.1:1; y = x.^2;
A = trapz(x, y)                       % area under sampled data
r = fzero(@(x) cos(x) - x, 0.5)       % root of one equation
sol = fsolve(@(v) [v(1)^2 + v(2)^2 - 4; v(1) - v(2)], [1; 1])
[xmin, fmin] = fminsearch(@(v) (v(1) - 1)^2 + (v(2) + 2)^2, [0 0])
yi = interp1([0 1 2], [0 10 15], 1.5)  % interpolation

Differential equations

Write the equation as a first-order system dy/dt = f(t, y). Example: a damped oscillator m x'' + c x' + k x = 0 with state y = [x; v]:

m = 2; c = 4; k = 800;
f = @(t, y) [y(2); -(c*y(2) + k*y(1))/m];
opts = odeset('RelTol', 1e-8);
[t, y] = ode45(f, [0 2], [0.01; 0], opts);
plot(t, y(:, 1)); grid on; xlabel('t (s)'); ylabel('x (m)')

Use ode23 for rough problems and ode15s for stiff ones.

Statistics, data and polynomials

data = [9.8 10.1 9.9 10.3 9.7 10.0];
mu = mean(data), s = std(data), med = median(data)
[h, p] = ttest(data, 10)          % is the mean different from 10?
p2 = polyfit(1:6, data, 1);       % straight-line fit
fitted = polyval(p2, 1:6);
r = roots([1 -3 2])               % roots of x^2 - 3x + 2
X = fft(sin(2*pi*5*(0:0.01:0.99)));

Symbolic mathematics

syms x t s
f = x^3 - 2*x;
df = diff(f, x)                   % derivative
F = int(f, x)                     % indefinite integral
area = int(f, x, 0, 2)            % definite integral
xs = solve(x^2 - 4 == 0, x)       % equation
S = solve({x + t == 3, x - t == 1}, {x, t});
G = laplace(exp(-2*t), t, s)      % Laplace transform
g = ilaplace(1/(s + 1))
h = matlabFunction(df);           % numeric function from an expression
h(2)

Animation and export

figure;
for k = 1:20
    x = linspace(0, 2*pi, 100);
    plot(x, sin(x - k/5)); ylim([-1 1]); grid on
    drawnow                % shows each frame (about 30 frames per second)
end
saveas(gcf, 'last_frame.png');

drawnow limitrate skips frames for speed, pause(t) waits, and h = animatedline; addpoints(h, x, y) grows a line point by point. exportgraphics(gcf, 'anim.gif', 'Append', true) adds one frame to an animated GIF each time it is called. print('-dpdf', '-r300', 'name') controls format and resolution.

Control systems

Linear systems are values, like numbers: create them, combine them with operators, and pass them to analysis and plot commands.

s = tf('s');
G = 1/(s*(s + 1)*(s + 5));         % plant
C = pidtune(G, 'PID');             % controller for about 60 degrees phase margin
T = feedback(C*G, 1);              % closed loop with unity feedback
info = stepinfo(T)                 % rise time, overshoot, settling time, ...
figure; step(T); grid on
figure; margin(C*G)                % Bode plot with margins
p = pole(T);
  • Create: tf(num, den), tf('s'), zpk(z, p, k), ss(A, B, C, D); discrete with tf(num, den, Ts) or c2d(G, Ts).
  • Combine: G1*G2 (series), G1 + G2 (parallel), feedback(G, H) (negative feedback), minreal.
  • Analyse: pole, zero, dcgain, damp, isstable, stepinfo, margin.
  • Plot: step, impulse, initial, lsim, bode, nyquist, rlocus, pzmap; several systems can be drawn together: step(G, 'b', T, 'r--'). With outputs they return data: [y, t] = step(G).
  • PID: pid(Kp, Ki, Kd, Tf), pidstd(Kp, Ti, Td), pidtune(G, 'PI') or pidtune(G, 'PID', wc) for a chosen crossover frequency.

Simulation (block diagrams)

The model editor builds Simulink-style block diagrams: drag blocks from a library, wire them, set parameters, press Run and look at the Scope windows. Models are saved as .esmodel files and can also be run from scripts with sim.

Opening the model editor

  • Simulation → New Model or Simulation → Open Model... in the main window;
  • double-click an .esmodel file in the Current Folder panel;
  • from a script: open_system('model.esmodel').

Running and settings

Run (Ctrl+R) starts the simulation in the background (a progress bar shows in the status bar); Stop ends it. When it finishes, every Scope opens a figure window with its signals against time, and the status bar shows the number of points and the final values of Display blocks. If a run fails, the message names the block, and that block is selected.

Settings (Ctrl+E):

SettingMeaning
Start time, Stop timeSimulated time interval in seconds.
Solverode45 (default, general), ode23 (rough problems), ode15s (stiff), ode113, or fixed-step rk4 and euler.
Relative / absolute toleranceAccuracy of variable-step solvers (smaller is more accurate and slower).
Max stepLargest allowed step (use it so short pulses are not skipped).
Fixed stepStep size for rk4 and euler.
Algebraic loops. Every feedback loop must contain a block with memory or dynamics (Integrator, Transfer Fcn with more poles than zeros, State-Space, Unit Delay, ...). Otherwise the run stops with an "algebraic loop" message listing the blocks in the loop.

Tutorial: mass-spring-damper

Model m x'' + c x' + k x = F(t) with m = 1 kg, c = 0.4 N s/m, k = 4 N/m and a 1 N step force:

  1. New Model. Add a Step (StepTime 0, Final 1), a Sum with Signs +--, a Gain with K = 1 (that is 1/m), two Integrator blocks, two Gain blocks with K = 0.4 (c) and K = 4 (k), and a Scope.
  2. Wire Step → Sum input 1, Sum → Gain(1/m) → Integrator 1 (output is velocity) → Integrator 2 (output is position) → Scope.
  3. Feed velocity through Gain c into Sum input 2, and position through Gain k into Sum input 3.
  4. Settings: Stop time 20. Press Run: the Scope shows the position settling at F/k = 0.25 m.

A finished version of this model ships as examples/models/mass_spring_damper.esmodel; pid_position_loop.esmodel and sampled_control.esmodel show feedback control with a PID block and with discrete blocks.

Running models from scripts

out = sim('mass_spring_damper.esmodel');     % run; results in a struct
plot(out.tout, out.x); grid on                % To Workspace block named x
sim('pid_position_loop', 'StopTime', 5)       % no output: Scope figures open, out is set
out = sim('model', 'Solver', 'rk4', 'FixedStep', 1e-3);

out.tout is the time column; each To Workspace block adds a field named after its VariableName (one column per signal element), and top-level Outports are collected in out.yout. Options: 'StartTime', 'StopTime', 'Solver', 'RelTol', 'AbsTol', 'MaxStep', 'FixedStep'. Model files are looked up in the working folder and next to the running script. Stop (Shift+F5) also stops a sim call.

All blocks and their parameters are listed in the block reference.

Engineering toolboxes

They are called like any other function; results with several values come back as a struct (read fields with a dot, e.g. p.wn), several outputs as [a, b] = f(...).
